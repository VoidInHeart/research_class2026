# SGD 两层执行路由本地试点

2026年11月18日。使用10个固定 SGD 训练分片，按完整对话划分，比较两种第一层编码器。两组共用相同的检索式专家池、通用检索兜底、17维已知意图目录和执行评分规则。下游输出为服务、方法和参数。下表为三项联合完全匹配率。

| 策略 | TF-IDF 第一层 | MiniLM 第一层 |
| --- | ---: | ---: |
| 固定走通用基座 | 7.81% | 7.81% |
| OOS 走基座，其余固定最佳专家 | 7.43% | 7.90% |
| 首选意图查表 | 7.62% | 8.27% |
| 全向量加权能力表 | 7.81% | 8.18% |
| 全向量小型 MLP | 7.25% | 7.90% |
| 原文嵌入对照 | 7.06% | 6.97% |
| 关闭 OOS 门的全向量加权 | 5.86% | 6.69% |

4,080个可评分请求分为1,852条 fit、598条路由监督、554条校准及1,076条测试。测试集有297段独立对话，820条真实已知请求和256条来自两个最终未知意图的请求。两种编码器在同一批样本上比较。随机种子均为1118。最少的已知意图只有3条 fit 样本。

**完整向量相对查表的收益在本试点中不稳定。** MiniLM 加权路由改变了272次选择，救回2条、损失3条，总计少做对1条。完整调用正确率差为 −0.09 个百分点，对话聚类配对95%区间约为 [−0.49，+0.28] 个百分点。TF-IDF 上加权路由净多做对2条。两次 MLP 均达到设定的250次迭代上限，优化器未报告收敛。

**执行池限制了端到端上界。** 若事后能在三个检索专家和通用检索基座中任选，完整调用正确率上界为11.52%。MiniLM 对真实未知的 OOS 召回为49.61%，对真实已知的误回退率为29.88%。它最终将372条请求送给基座，其他请求在 search、transaction、context 三专家上分别选择196、364、144次。通用基座对真实未知请求的完整调用正确率为15.23%。正确回退与生成正确调用是两个不同的统计量。

**开销测量。** 每种策略在24条真实请求上预热后交错运行两遍。MiniLM 加权路由的端到端中位数为17.12毫秒，P95为27.34毫秒。它在48次请求中实际调用第二层30次，这30次的第二层均值约为0.068毫秒。测量对象是本机 CPU 检索执行器，执行大模型的生成耗时及 Jev 往返和账单须另测。质量统计使用冻结决策对应的执行输出，时延则重新调用执行器。

**验证范围。** 两种识别器已在真实数据跑完全流程。可选 LoRA 模块用微型随机 GPT-2 做了实际 PEFT 参数更新、保存、重载、生成及基座回退检查。正式指令基座上的任务质量需独立训练评估。Jev 的直接选择、共享门、无效返回以及费用留空逻辑已经过模拟测试，本次没有托管 Jev 的实测结果。
