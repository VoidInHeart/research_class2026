# 用已知样本的近邻证据改进近域 OOS 门控

2026-11-18 · SGD · 本地 MiniLM 和冻结的检索执行池

**按开发集选择的融合门，在三种“查询已知、交易未知”的新对话上都提高了未知拦截率。** 在相同的已知误拒预算下，公交购票、住宿预订、活动购票分别多拦 15、51、39 条。公交仍漏放 199/218 条。主分支新增显式选项 `--oos-gate adaptive-support`，通用默认继续使用原型门。这个结论只覆盖第一层拒识，当前执行池的完整调用成功率没有一致提升。

## 门控从哪些证据做判断

输入仍是最近五条公开发言。原型门比较这段对话和每个已知意图平均向量的相似度。新增的语义特征衡量同一已知意图中最相似的三个历史样本与当前请求有多接近，用冻结的 MiniLM 向量逐类计算。词面特征衡量历史样本和当前请求在用词上有多接近，用已知拟合集的单词和相邻词对构建 TF-IDF，取最大余弦相似度。每项分数都转换为越大越陌生，并在独立的已知路由监督集上按中位数和四分位距缩放。

开发时，轮流隐藏一个原本已知的意图，移除拟合数据中提及它的整个对话与关联模板。在路由监督对话上模拟遇到这个未知意图，按各隐藏意图等权的召回率，从六组预设权重中选一组。公交、住宿、音乐选出原型/语义/词面权重 25%/25%/50%，活动和原天气/账户组为 25%/50%/25%。权重按拟合时的已知意图目录确定，每个模型在预测时用一组固定权重。新门只决定进专家池还是走兜底。已知意图向量、放行时的矩阵路由和三个执行专家都与对照共用。

## 独立验证与相同误拒比较

旧实验使用 10 个官方 SGD 训练分片。开发选择和阈值在查看新分片成绩前锁定，协议提交为 `0155c4e`，开发锁提交为 `70d49d3`。验证另用同版本的 19 个训练分片，含 6,885 条可评分请求。按每折意图目录筛选整段对话，并隔离与旧数据共享长、短窗口规范化模板的对话组件。五折共 16,661 个折内观测，涉及 3,820 个不同请求、1,359 段不同对话。各折共享大量对话，因此逐折比较。测试未知未用于训练本折门控、选择权重或拟合路由矩阵。既有专家在历史训练中见过部分近域交易类别。该实验检验同一执行池上门控的作用，属于官方训练集内的自建留出验证。

在相同校准规则下，融合在三个近域组都减少了已知误拒并多拦了未知。公交只多拦 3 条，配对召回差的 95% 区间为 [0.00, 3.87] 个百分点。与现行默认直接比较，融合在公交和住宿放行了更多已知请求，也漏过更多未知请求。天气/余额融合阈值的实际误拒达到 780/3,600（21.67%），超过校准目标，也是保留通用默认的原因。

## 识别、路由与执行分别发生了什么

无论门控如何选择，所有真实已知请求的首选意图相同。公交、住宿、活动三折 Top-1 分别为 2,557/3,018、2,592/3,099、2,552/3,030。门控改变的请求只在原矩阵选定的专家与兜底之间切换。

在相同误拒数下，公交购票的服务和方法正确从 13/218 到 18/218。三个近域组的每条未知交易，无论交给矩阵选中的专家还是兜底，都没有一次把服务、方法和全部参数同时答对。因此近域完整正确数的变化全部来自已知请求的分流。就全部请求而言，三折的完整成功率配对差依次为 −0.12、0.00、+0.03 个百分点，95% 区间分别为 [−0.31, +0.06]、[−0.15, +0.15]、[−0.12, +0.19]。现有证据支持近域拒识这个用途；端到端收益需要能正确执行这些交易的兜底或专家另行验证。

## 复现

只核对本文的计数与配对区间，需要 Python 和项目数值计算依赖。以下命令从归档逐请求记录重算，无需原始对话、权重或网络。

```powershell
python -m intentexec.support_study replay --out reports/support_validation
```

完整重跑使用本地 MiniLM、原 10 个分片和原检索试点 `artifacts/verified-minilm`。首次运行下载脚本需要访问 SGD 的公开静态文件，已有分片时直接核对摘要。每次实验使用新的输出目录。

```powershell
python -m scripts.fetch_support_holdout
python -m intentexec.support_study prepare --out artifacts/my-support-development
python -m intentexec.support_study validate --lock artifacts/my-support-development --out artifacts/my-support-confirmation
python -m intentexec.support_study replay --out artifacts/my-support-confirmation
```
